# UI_GUIDELINES.md

## 1. Visual direction

- polished modern SaaS
- white/off-white base
- dark readable typography
- restrained purple accent
- subtle border/shadow
- compact information density
- avoid giant cards
- avoid tiny text inside oversized containers

Reference direction: Ticking/Linear/Vercel 계열의 정돈된 제품 UI 감각을 참고하되 복제하지 않는다.

## 2. Public landing

Hero copy는 특정 학원에 고정되지 않는다.

Recommended:
> 고객에게 집중하세요. 운영은 한 곳에서.

Supporting:
> 예약부터 고객 관리, 결제, 재방문까지. 사업장의 운영 방식에 맞춰 필요한 기능만 구성하세요.

Product preview:
- segmented `레슨 / 스튜디오` / `뷰티 / 예약샵`
- 동일한 visual frame
- mode에 따라 내용/메뉴만 변경

## 3. Terminology

Public/common:
- 고객
- 예약
- 결제

LESSON inside app:
- 회원
- 수업
- 이용권
- 출석
- 재등록

BEAUTY inside app:
- 고객
- 예약
- 시술
- 재방문

## 4. Controls

업종/모드 선택은 compact cards 또는 segmented controls 사용.
단, subtype hierarchy를 시각적으로 분명히 한다.

## 5. Responsive

- desktop admin first
- tablet usable
- customer booking portal mobile-first

## 6. Do not

- LESSON 선택 화면에 네일 카드 표시
- BEAUTY 선택 화면에 출석/회차권 표시
- decorative dashboard cards만 잔뜩 배치
- 기능 의미보다 시각효과를 우선
