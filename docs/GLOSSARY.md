# GLOSSARY.md

| Term | Meaning |
|---|---|
| Studio | 하나의 사업장/tenant |
| User | SaaS에 로그인하는 운영자 계정 |
| StudioMembership | User가 Studio에 속하는 관계와 role |
| Customer | 해당 Studio의 고객. LESSON UI에서는 회원이라고 표시 가능 |
| Staff | 수업/시술 담당자 |
| BusinessCategory | LESSON 또는 BEAUTY |
| BusinessType | Category 내부 세부 업종 |
| StudioCapabilities | 실제 활성 기능 집합 |
| Booking | 예약 |
| BookingBlock | 운영자가 예약을 막아둔 시간 |
| PassProduct | LESSON 사업장이 판매하는 이용권 상품 |
| Enrollment | 고객이 레슨/반/이용권 관계에 등록된 상태 |
| EnrollmentCycle | 재등록 단위의 이력 세트 |
| PassUsageLedger | 회차 증감 이력 |
| Class | 그룹 수업/반 |
| Attendance | 수업 출석 기록 |
| BeautyService | 뷰티 시술 메뉴 |
| TreatmentRecord | 완료된 시술 기록 |
| Revisit | 재방문 예정/권장 정보 |
| Deposit | 예약금 |
| Operator Portal | 사업장 운영자용 관리자 화면 |
| Customer Booking Portal | 고객이 직접 예약하는 외부 페이지 |
